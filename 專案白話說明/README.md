## 一句話版本

> 求職者打一句白話文（例如「台北 前端工程師 35k以上」），
> 我們用 AI 把它翻譯成結構化條件，
> 從 100 萬筆職缺裡撈出符合的，
> 再依「熱門度 + 個人偏好」排序，回傳最相關的前 10 筆。
