# Dataset 說明

本目錄包含 2026-06-01 至 2026-06-07 期間的職缺、求職者搜尋、職缺瀏覽與主動應徵資料，以及城市、職務分類對照表。

## CSV 檔案與欄位

### `userSearchLog_20260601_20260607.csv`

求職者搜尋紀錄與搜尋結果職缺清單。

| 欄位 | 說明 |
| --- | --- |
| `talentNo` | 求職者編號。可與瀏覽、主動應徵資料的 `talentNo` 串接。`0` 可能代表未登入或無法識別的使用者。 |
| `ks` | 搜尋關鍵字。 |
| `c0` | 搜尋條件中的地區代碼，逗號分隔時代表多個地區；可參考 `城市對照表.csv` 的 `CodeNo`。 |
| `d0` | 搜尋條件中的職務代碼，逗號分隔時代表多個職務；可參考 `職務對照表.csv` 的 `CodeNo`。 |
| `search_time` | 搜尋時間。 |
| `empStr` | 搜尋結果中的職缺編號清單，逗號分隔；可對應 `職缺.csv` 的 `職缺編號`。 |

Header：`talentNo`, `ks`, `c0`, `d0`, `search_time`, `empStr`

### `主動應徵_0601-0607.csv`

求職者主動投遞職缺的紀錄。

| 欄位 | 說明 |
| --- | --- |
| `LogTitle` | 行為類型，本檔多為主動應徵。 |
| `empNo` | 被應徵的職缺編號；可對應 `職缺.csv` 的 `職缺編號`。 |
| `empName` | 應徵當下記錄的職缺名稱。 |
| `talentNo` | 求職者編號。可與搜尋、瀏覽資料的 `talentNo` 串接。 |
| `datein` | 主動應徵時間。 |

Header：`LogTitle`, `empNo`, `empName`, `talentNo`, `datein`

### `城市對照表.csv`

地區代碼對照表，用於解讀搜尋條件中的城市/地區代碼。

| 欄位 | 說明 |
| --- | --- |
| `CodeNo` | 地區代碼。可與 `userSearchLog_20260601_20260607.csv` 的 `c0` 對照。 |
| `CodeNameA` | 地區名稱，通常為最細層級名稱。 |
| `CodeNameB` | 上層或群組地區名稱。 |
| `CodeNameC` | 更高層級地區名稱。 |
| `CodeType` | 地區層級或類型。 |
| `CodeArea` | 區域代碼。 |
| `CodeZip` | 郵遞區號或相關郵遞資訊。 |

Header：`CodeNo`, `CodeNameA`, `CodeNameB`, `CodeNameC`, `CodeType`, `CodeArea`, `CodeZip`

## 資料表關係

```text
城市對照表.CodeNo ── userSearchLog.c0（逗號分隔，多值搜尋條件）
職務對照表.CodeNo ── userSearchLog.d0（逗號分隔，多值搜尋條件）

職缺.職缺編號 ── 主動應徵.empNo
職缺.職缺編號 ── 職缺瀏覽.employeeNo
職缺.職缺編號 ── userSearchLog.empStr（逗號分隔，多個搜尋結果職缺）

職缺.廠商編號 ── 職缺瀏覽.organNo

userSearchLog.talentNo ── 職缺瀏覽.talentNo ── 主動應徵.talentNo
```

### 關係說明

- `職缺.csv` 是職缺主檔，`職缺編號` 是串接瀏覽、應徵與搜尋結果的主要 key。
- `talentNo` 是求職者行為 key，可用來串接同一求職者的搜尋、瀏覽、主動應徵路徑。
- `userSearchLog_20260601_20260607.csv` 的 `empStr`、`c0`、`d0` 都可能包含逗號分隔的多個值，分析前需先拆展成多列或陣列。
- `城市對照表.csv` 與 `職務對照表.csv` 是代碼維表，主要用來解讀搜尋條件；`職缺.csv` 中的工作城市與職務分類已是中文名稱，可用名稱與對照表交叉參考。
- `職缺瀏覽_20260601_20260607.csv` 同時保留職缺編號 `employeeNo` 與廠商編號 `organNo`，可分析求職者對單一職缺或同一廠商的瀏覽行為。
- `主動應徵_0601-0607.csv` 可視為轉換行為資料，能與搜尋、瀏覽紀錄依 `talentNo` 與職缺編號建立漏斗分析。

## 分析注意事項

- 多值欄位：`empStr`、`c0`、`d0` 需先用逗號切分。
- 匿名或未登入使用者：`talentNo = 0` 不適合直接視為同一位求職者。
- 代碼對照：搜尋條件中的部分地區/職務代碼可能是上層分類、歷史代碼或不在目前對照表內的值；使用對照表時需保留未匹配代碼。
- 時間欄位：`search_time`、`datein`、`dateIn` 可統一轉成 timestamp 後做跨表行為序列分析。
